# Modulero AI — инструкции для Claude Code

ИИ-диалог для конструктора мебели Modulero: человек пишет «Хочу кухню», помощник уточняет вопросами и после каждого ответа показывает прототип от движка конструктора. Отвечай по-русски.

## Перед любой работой
- Прочитай `README.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md` и пакет старта `docs/start/`: `RULES.md` (правила проекта), `IDEA_AND_SCOPE.md`, `EXCHANGE_SPEC.md` (договор ИИ ↔ конструктор), `SYSTEM_PROMPT_DRAFT.md` (правила помощника), `TASK_FIRST.md`.
- Нужен Node 24 (`.nvmrc`). Команды — `npm` / `npx`; на Windows владельца — `npm.cmd` / `npx.cmd`.

## Главный принцип
ИИ не считает конструкцию и цену, а вызывает движок. Слова человека → правки из закрытого списка (`EXCHANGE_SPEC.md`) → редактор ядра Modulero → новая версия или отказ словами движка. В коде этого репозитория нет формул размеров, деталей, фурнитуры и цены. Отказ движка не обходится. Неизвестная цена не становится числом, неполная цена называется неполной.

## Режим сейчас (владелец, 2026-10-28; AI-DEC-001)
- Без Claude API: ключа нет, запросов к API нет, зависимостей `@anthropic-ai/*` нет (проверяет `npm run check`). Роль ИИ из диалога играет Claude в треде проекта.
- Без публикации: на сайт и сервер Modulero ничего не выкладывается.
- AR, фото и голос не делаем.

## Модуль modulero-next
`proc2010-Claude/modulero-next` — только чтение, на закреплённом SHA (AI-DEC-003). Код modulero-next не меняем. Чего не хватает в конструкторе — задача MOD-AI-N для Modulero (`EXCHANGE_SPEC.md` §8), а не обходной путь здесь.

## Условие приёмки
`npm run check` — быстрая проверка без ИИ и без сети: Node 24, имена латиницей, отсутствие API, типы, тесты (sha256 входов, схемы инструментов, позже — проигрыш записанных вызовов сценариев). Должна закончиться строкой `All checks passed.` Итог, SHA и версию Node — комментарием в PR.

## Git и PR
1. В `main` не коммитить. Каждая задача — своя ветка от свежего `main` и один PR.
2. Коммиты по-русски, первая строка до 72 символов, ниже — зачем.
3. В PR: что сделано, как проверено, что осталось, решения для владельца.
4. Исполнитель PR не сливает: сливает Директор после зелёного `npm run check` на SHA с текущим `main`.
5. Нестабильный тест не перезапускать до случайного успеха — задача на починку.

## Правила
- `reference/**` хранится побайтно и сверяется по `SHA256SUMS`: не пересохранять редактором.
- Имена файлов и папок — только латиница.
- Журнал решений — `docs/DECISIONS.md`, номера `AI-DEC-NNN` выдаёт Директор. Предложение без решения помечается (Д).
- Внешние материалы и библиотеки — только записанные в `docs/SOURCES.md`, версии закреплены.
- В сценариях и сеансах — только вымышленные данные: без имён, телефонов, email, адресов. В ответах стенда — только то, что видно на экране конструктора (MOD-DEC-497).
- Защитный запрет среды не обходится; технический сбой — поддержанными средствами.
