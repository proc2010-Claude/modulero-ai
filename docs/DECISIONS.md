# Журнал решений ИИ-диалога Modulero

Номера `AI-DEC-NNN` выдаёт Директор. Предложение без решения владельца помечается (Д) — решение Директора, которое владелец может пересмотреть.

## AI-DEC-001. Режим: без Claude API и без публикации
- Дата: 2026-10-28. Статус: действует. Источник: владелец.
- Ключ Claude API не заводится, запросов к API нет. Роль ИИ из диалога играет Claude в треде проекта по `docs/start/SYSTEM_PROMPT_DRAFT.md` и меняет прототип только вызовами стенда.
- На сайт и сервер Modulero ничего не выкладывается; прототип — страница сеанса (файл HTML или частная страница Artifact).
- AR, фото и голос не делаются.
- Подключение API и сайта — только отдельным решением владельца.

## AI-DEC-002. Договор ИИ ↔ конструктор — EXCHANGE_SPEC 0.1-draft (Д)
- Дата: 2026-10-28. Статус: действует как рабочий черновик.
- Рабочий договор — `docs/start/EXCHANGE_SPEC.md` 0.1-draft и `reference/start/examples/tools.claude-api.json` (10 инструментов, strict). Меняется только записью в этом журнале по согласованию с Modulero; несовместимое изменение — новая старшая версия.

## AI-DEC-003. Основа движка — modulero-next cbaf1534, каталог hw-2026-10-27.8 (Д)
- Дата: 2026-10-28. Статус: действует.
- Стенд использует `proc2010-Claude/modulero-next` только для чтения, на закреплённом SHA `cbaf1534` (основа примера в `reference/start/`) и выпуске каталога фурнитуры `hw-2026-10-27.8`. Переход на новый SHA — отдельный PR с проигрышем сценариев и новой записью.

## AI-DEC-004. Пакет старта в репозитории (Д)
- Дата: 2026-10-28. Статус: действует.
- Документы пакета — `docs/start/` (копия как есть), примеры и скрипт прогона — `reference/start/` побайтно, с `SHA256SUMS`; sha256 файлов проекта, журнала и инструментов совпадают с `docs/start/README.md` (проверяет `npm run check`). Картинки сверяются по `SHA256SUMS` репозитория.

## AI-DEC-005. Проверка без GitHub Actions на старте (Д)
- Дата: 2026-10-28. Статус: действует до решения владельца.
- `npm run check` запускается исполнителем на Node 24 на точном SHA, итог — комментарием в PR. Рабочий процесс GitHub Actions не заводится, пока владелец не решит про расход минут Actions в приватном репозитории.
