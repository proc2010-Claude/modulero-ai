# Журнал решений ИИ-диалога Modulero

Номера `AI-DEC-NNN` выдаёт Директор. Предложение без решения владельца помечается (Д) — решение Директора, которое владелец может пересмотреть.

## AI-DEC-001. Режим: без Claude API и без публикации
- Дата: 2026-10-28. Статус: действует. Источник: владелец.
- Ключ Claude API не заводится, запросов к API нет. Роль ИИ из диалога играет Claude в треде проекта по `docs/start/SYSTEM_PROMPT_DRAFT.md` и меняет прототип только вызовами стенда.
- На сайт и сервер Modulero ничего не выкладывается; прототип — страница сеанса (файл HTML или частная страница Artifact).
- AR, фото и голос не делаются.
- Подключение API и сайта — только отдельным решением владельца.

## AI-DEC-006. Оценка расхода Claude API в «Режиме диалога» (Д)
- Дата: 2026-10-28. Статус: действует. Источник: владелец (просьба оценивать стоимость помощи при работе через API), номер — Директор.
- После каждого ответа помощника стенд оценивает, сколько ушло бы через Claude API на этот ход и на весь сеанс: запросы, токены (запись и чтение кэша, выход) и доллары — для `claude-opus-5-5` (модель предложения, `EXCHANGE_SPEC.md` §7), для сравнения `claude-sonnet-5-5` и `claude-haiku-5-5`. Итог — в `sessions/<сеанс>/usage.json`, на странице прототипа и строкой под ответом в треде.
- Цены за 1 млн токенов на 2026-10-28 (страница цен Anthropic, `docs/SOURCES.md`): Opus 5.5 — вход $4, запись кэша 5 мин $5, чтение кэша $0,20, выход $20; Sonnet 5.5 — $2 / $2,50 / $0,10 / $10; Haiku 5.5 (до 100 тыс. токенов запроса) — $0,10 / $0,125 / $0,01 / $0,50.
- Запросов к API нет, поэтому это оценка: токены — по длине текста (3 знака латиницы и JSON или 2 знака кириллицы на токен), рассуждения — 300 токенов на ответ модели (effort `medium`), служебный промт инструментов — 286 токенов, кэш 5 минут без промахов между репликами; каждый вызов инструмента — отдельный ответ модели. Точность ±30–50 %; допущения — `src/stand/cost.ts`, уточняются замером `count_tokens` и `usage` на первом шаге этапа 3.
- В рубли не переводится: курс — отдельное решение.

## AI-DEC-007. Договор — на весь функционал конструктора, общим проходом к командам редактора
- Дата: 2026-10-28. Статус: действует. Источник: владелец — «расширяй договор на весь функционал конструктора» и «+ HOME» (сообщения в проекте `cmsg_01BF2d3wM1F8Kc8qD65oFYcZWLNAvdX9F7D4kkK7AADTBZ`, `cmsg_01BF2d3wM1F8Kc8qD65oFYcZ5PfXYphAXphANwXDMzoyZB`); уточнение владельца: это исследование, стоит ли добавлять помощника, в modulero-ai — что требуется, modulero-next не трогать. Номер — Директор.
- Правки не описываются вручную по одной. Стенд получает общий проход ко всем командам редактора ядра для кухни, распашного шкафа, купе и другой мебели (HOME): список команд и схемы их параметров снимаются с типов TypeScript ядра на закреплённом SHA (`scripts/commands.ts` → `contract/commands-cbaf1534.json`, `npm run check` сверяет файл с ядром).
- Расширение договора 0.2-draft — `contract/tools-0.2-draft.json`: `list_commands` (команды изделия с описанием из кода ядра и параметрами) и `editor_call` (команды по порядку, ответ как у `*_edits`). `reference/start/examples/tools.claude-api.json` 0.1-draft не меняется, его правки работают как раньше.
- Проверки и отказы — ядра: команда вызывает ту же функцию, что кнопка редактора; шкаф после неё проверяется построением графа, HOME — `validate`. Своих формул на стенде нет.
- Не команды стенда (MOD-DEC-497): ставки, валюта и раскрой мебельщика (`setKitchenRates`, `setKitchenCurrency`, `setKitchenCutting`, `wardrobe setCutting`), создание проекта (это `start_project`). Список исключений — в том же файле, поле `skipped`.

## AI-DEC-008. Цена — на прототипе в углу 3D, не в тексте ответа помощника (Д)
- Дата: 2026-10-28. Статус: действует. Источник: владелец — «текущую стоимость мебели — отображай в левом нижнем углу поля с 3Д, в тексте ответа помощника не пиши» (`cmsg_01BF2d3wM1F8Kc8qD65oFYcZ3jGA4puivcKa6jmvJuVk6v`). Номер — предложение исполнителя до подтверждения Директором.
- Страница прототипа показывает текущую цену в левом нижнем углу поля 3D: «Ориентир N ₽» или «Известная часть N ₽ · цена неполная» — поля полосы цены из ответа стенда.
- Помощник сумму в тексте не называет; при неполной цене — одной фразой, что цена неполная и чего не хватает. Правило — `docs/start/SYSTEM_PROMPT_DRAFT.md` «После правки» и `CLAUDE.md` «Режим диалога» п. 2; проверка реплик сценариев — `answerProblems` (`src/stand/scenario.ts`).
- Сценарии, записанные раньше, помечены `price_in_answer: true` и проверяются по прежнему правилу (суммы — из ответа стенда); новые — по этому.
