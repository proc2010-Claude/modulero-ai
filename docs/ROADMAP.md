# План ИИ-диалога Modulero

Статус задач ведёт Директор в чате проекта; здесь — этапы и границы.

## Этап 0. Каркас
Репозиторий, `CLAUDE.md`, `npm run check` на Node 24, журнал решений, план, внешние материалы, пакет старта в `docs/start/` и `reference/start/`.

## Этап 1. Стенд и кухня в треде (`docs/start/TASK_FIRST.md`)
1. Стенд движка: `npm run dialog -- <инструмент> '<JSON>'` — `start_project`, `get_options`, `kitchen_edits`, `get_project`, `undo`, `variants` функциями ядра modulero-next (только чтение, `cbaf1534`, `hw-2026-10-27.8`). Ответ — `EXCHANGE_SPEC.md` §5.
2. Сеанс на диске `sessions/<имя>/`: файл проекта каждой версии, история с подписями, журнал вызовов, текст диалога.
3. Страница прототипа после каждой правки: превью, план, состав, цена «полная / неполная», история, лента диалога.
4. «Режим диалога» в `CLAUDE.md`: Claude отвечает как помощник по `SYSTEM_PROMPT_DRAFT.md`, только через стенд.
5. 12 сценариев кухни с ожидаемым состоянием, отказами и критериями ответа.
6. `npm run check` проигрывает записанные вызовы сценариев; пример §6 даёт те же `KPR2-…` и суммы, что `kitchen-dialog.log.json`.
7. Разбор 12 сценариев в треде и отчёт владельцу: задачи MOD-AI-N, следующий этап, когда подключать API.

## Этап 2. Все изделия в треде
Шкаф, купе, другая мебель, варианты, отмена, трудные сценарии (не меньше 30 диалогов, `EXCHANGE_SPEC.md` §9).
1. Шкаф и купе на стенде: `wardrobe_edits` функциями редактора шкафа ядра (`src/stand/wardrobe.ts`), страница прототипа с 3D конструктора, файл версии открывается в конструкторе и на странице с лентой; 8 сценариев `scenarios/wardrobe/` (отчёт `docs/reports/2026-10-28-stage2-wardrobe.md`).
2. Весь функционал конструктора (AI-DEC-007): общий проход `list_commands` / `editor_call` ко всем командам редактора кухни, шкафа, купе и HOME, список снят с типов ядра; другая мебель на стенде (`home_edits`); сценарии `w09`, `k14`, `h01` (отчёт `docs/reports/2026-10-28-stage2-all-commands.md`).
3. Эргономика наполнения шкафа: раздел «Наполнение шкафа» в `SYSTEM_PROMPT_DRAFT.md` (зоны по высоте, штанги, полки, ящики, антресоль, вопрос «что хранить»); шаблонов наполнения в ядре нет; сценарии `w10-fill-zones`, `w11-fill-ask`. Перечень эргономики по руководству ARDI / Blum для всех изделий — `docs/ergonomics/ASSISTANT_RULES.md` (AI-DEC-011, штанга выше 2000 мм — с пантографом).
