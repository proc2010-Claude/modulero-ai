# Переход стенда на modulero-next 1582b93e (AI-DEC-009)

Основа стенда: `cbaf1534` (каталог `hw-2026-10-27.8`) → `1582b93ef67ccf588cc565cd8cdbce8da270b4d8` (main на 2026-10-29,
каталог `hw-2026-10-29.17`). Между ними 593 коммита modulero-next, в их описаниях — MOD-AI-11…80.

## Что сделано

- `engine.json`: SHA, папка `vendor/modulero-next-1582b93e`, каталог, `manifestSha256` (sha256 файла MANIFEST копии).
  Список `paths` не менялся: `glass.json` и `worktops.json` лежат в `catalogs/materials`. Копия — 13 МБ.
- `contract/commands-1582b93e.json` (`npm run contract:commands`): 35 новых команд редактора, ни одна не пропала,
  параметры старых не изменились. Новые: кухня — `replaceKitchenModule`, `setKitchenWorktop`, `setKitchenFittings`,
  `setKitchenCutout`, `setKitchenSinkMount`, `setKitchenApplianceNiche`, `setKitchenAppliancePlace`,
  `setKitchenIslandOverhang`, `updateKitchenObstacle`, кромка; шкаф — `setSectionWidths`, `removeRod`, `moveDrawerBlock`,
  `setDrawerBlockHeight`, кромка; HOME — `setMirror`, `setTopCorners`, `setDoorGlass`, `setLight`, `setNichePanel`,
  `setRim`, `setCable`, `setDoorLift`, `setDeskPedestal`, `setDecor`, `moveFront`, `setPushToOpen`, `setBayWidth`,
  `equalBays`, `equalDrawers`, `freeRoom`, кромка.
- Конструктор для страницы прототипа — `vendor/modulero-next-1582b93e-web/modulero-next.html` (6,6 МБ), собран как
  записано в `BUILD.json`: `git archive 1582b93e`, `npm ci --ignore-scripts`, `node scripts/build.mjs --no-typecheck`;
  повторная сборка даёт тот же sha256 `018448a2…`. Путь — от `engine.json` (`src/live/page.ts`).
- Копии `cbaf1534` и `commands-cbaf1534.json` удалены (остались в истории git). Тесты берут SHA из `engine.json`;
  `tools.test.ts` по-прежнему сверяет основу инструментов 0.1-draft пакета старта (`cbaf1534`) — это исторический файл.
- `npm run scenarios:rerecord` (`scripts/scenario-rerecord.ts`): проигрывает вызовы сценариев на новом ядре и печатает
  расхождения; с `--write` пишет новые ответы, версии во входах (undo по id версии) и `engine`. Реплики, ожидаемые отказы
  и разбор правятся руками по таблице ниже.
- Пример «Хочу кухню» записан заново — `reference/engine-1582b93e/` (побайтно, `SHA256SUMS`, прогон воспроизводим);
  `tests/stand-example.test.ts` сверяет стенд с ним. Пакет старта не тронут.
- Стенд: `remove_fill` штанги теперь вызывает `removeRod` ядра (R2-008, `456b336e`); на `cbaf1534` такой правки не было,
  стенд отказывал своими словами.
