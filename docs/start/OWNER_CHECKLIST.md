# Что сделать владельцу для проекта «ИИ-диалог Modulero»

## Создать

1. **Проект Claude** «ИИ-диалог Modulero». В инструкции проекта вставить `PROMPT_DIRECTOR.md` и `RULES.md`.
2. **Репозиторий** на GitHub, например `proc2010-Claude/modulero-ai` (приватный), основная ветка `main`. Установить на него приложение Claude, как на `modulero-next`, чтобы облачные сессии могли пушить ветки и открывать PR.
3. **Ресурсы проекта.** Подключить к проекту оба репозитория: `modulero-ai` (работа) и `modulero-next` (только чтение: стенд вызывает его движок, код не меняется).
4. **Среда облачной сессии** с Node 24 и доступом в сеть к npm, как у Modulero. Ключ Claude API и доступ к `api.anthropic.com` не нужны: роль ИИ из диалога играет Claude в треде проекта.

| `ai-dialog-start/examples/*` | Прогон примера на настоящем движке: журнал, 4 файла проекта, картинки |

## Сообщить директору

- Кто передаёт задачи MOD-AI-N в Modulero: вы сами или Директор Modulero по вашему сообщению.
- Как удобнее смотреть прототип: файл HTML в папке проекта или частная страница Artifact (видна только вам).

## Как попробовать самому

Когда стенд готов (первая задача), откройте тред проекта, напишите «Режим диалога», а затем как обычный покупатель: «Хочу кухню». Claude ответит как помощник с сайта и после каждой правки приложит страницу прототипа. «Выйти из режима диалога» возвращает обычную работу.

## Решить позже (не сейчас)

Эти вопросы появятся, только если вы решите выводить помощника на сайт. Директор принесёт их с вариантами, когда будут итоги сценариев в треде.

1. **Подключать ли Claude API:** ключ, лимит расхода, откуда идут запросы (сервер Modulero в Yandex Cloud) и как оплачивается.
2. **Модель.** По умолчанию `claude-opus-5-5`; после замера — оставить или перейти на более быструю и дешёвую.
3. **Квоты на реплики ИИ** для людей без входа и с аккаунтом.
4. **Журналы диалогов:** хранить ли обезличенные диалоги и сколько.
5. **Включение на сайте:** когда помощник становится видимым людям.

## В Modulero (передать Директору Modulero)

Задачи MOD-AI-1…7 из `EXCHANGE_SPEC.md` §8. Первой нужна MOD-AI-1 (API команд правки — часть PLAT-9) и MOD-AI-3 (понятные названия стен кухни). Для стенда и работы в треде от Modulero ничего не нужно; MOD-AI-1 и MOD-AI-6 нужны только для сайта.
