# Старт проекта «ИИ-диалог Modulero» (2026-10-28)

Человек пишет «Хочу кухню», ИИ уточняет параметры вопросами и сразу показывает прототип от движка конструктора, который меняется по ходу разговора. ИИ ничего не считает сам, а только вызывает движок. AR в проект не входит (владелец, 2026-10-28).

**Режим сейчас — без API и без публикации** (владелец, 2026-10-28). Роль ИИ из диалога играет Claude в треде нового проекта: он ведёт разговор по `SYSTEM_PROMPT_DRAFT.md` и меняет прототип вызовами локального стенда, который выполняет правки ядром `modulero-next`. Прототип виден на странице сеанса (файл HTML или частная страница Artifact). Ключ Claude API не нужен, на сайт ничего не выкладывается. Подключение API и сайта — позже, отдельным решением владельца.

- `START_HERE.md` — 5 шагов запуска нового проекта.
- `1_PROJECT_INSTRUCTIONS.txt` — инструкции проекта: сжатые промт директора и правила (≈ 5 300 знаков), вставить как есть; полные версии — `PROMPT_DIRECTOR.md` и `RULES.md`.
- `2_FIRST_MESSAGE.txt` — первое сообщение директору, вставить как есть.
- `PROMPT_DIRECTOR.md` — промт директора нового проекта.
- `RULES.md` — правила работы проекта (вставить в инструкции проекта вместе с промтом).
- `IDEA_AND_SCOPE.md` — идея, границы, что не делаем, риски.
- `EXCHANGE_SPEC.md` — договор ИИ ↔ конструктор 0.1-draft: инструменты, правки по изделиям с функциями ядра, формат ответа, пример «Хочу кухню», схема стенда, параметры Claude API на будущее, задачи MOD-AI-1…7 для Modulero.
- `SYSTEM_PROMPT_DRAFT.md` — правила помощника: по ним Claude ведёт диалог в треде (позже — системный промт для API).
- `OWNER_CHECKLIST.md` — что создать, положить и решить владельцу.
- `TASK_FIRST.md` — первая задача: стенд без API, страница прототипа, режим диалога в треде и 12 сценариев кухни.
- `examples/tools.claude-api.json` — 10 инструментов (strict JSON Schema; 13 правок кухни, 21 шкафа и купе, 12 другой мебели): их выполняет стенд, позже те же определения пойдут в Claude API. Имя файла и sha256 сохранены.
- `examples/kitchen-*` — прогон примера на настоящем движке: журнал вызовов и ответов, 4 файла проекта, превью трёх состояний.
- `tools/kitchen-dialog-run.mts` — скрипт прогона (не код репозитория; запуск из корня `modulero-next` после `npm ci`: `npx tsx <путь>/kitchen-dialog-run.mts <папка>`).
- `AI_DIALOG_START.html` — всё это на одной странице.

Основа: `modulero-next` `main` `cbaf1534`, каталог фурнитуры `hw-2026-10-27.8`, Node 22 (на стенде; правки ядра от версии Node не зависят).
