# Пример «Хочу кухню» на ядре modulero-next 1582b93e

Перезапись примера из пакета старта (`reference/start/examples/`, ядро `cbaf1534`) на новой основе стенда
(`engine.json`, AI-DEC-009): `proc2010-Claude/modulero-next` `1582b93ef67ccf588cc565cd8cdbce8da270b4d8`, каталог
`hw-2026-10-29.17`. Вызовы ядра те же, что в пакете старта; пакет старта не меняется — это исторический документ.

Файлы хранятся побайтно и сверяются по `SHA256SUMS` (`npm run check`, `tests/reference.test.ts`); стенд проигрывает
журнал и сверяет версии, отказы, цены и файлы шагов (`tests/stand-example.test.ts`).

Как получено (повторный прогон даёт те же байты):

```
git -C <клон modulero-next> archive 1582b93e | tar -x -C <папка>
cd <папка> && npm ci --ignore-scripts
MODULERO_NEXT_REPO=<папка> npx tsx <modulero-ai>/reference/engine-1582b93e/tools/kitchen-dialog-run.mts <выход>
```
